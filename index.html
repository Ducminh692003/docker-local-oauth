Docker Local

A private automation application operated by its owner using a local n8n installation.

What the application does

The application monitors an owner-selected Google spreadsheet, downloads product images referenced in its rows, uses the Gemini API to generate image-description prompts, and writes the resulting prompts back to that spreadsheet.

Google authorization lets the local application access the owner's selected spreadsheet and related file metadata. This application is for its owner's personal use. It does not offer public registration or provide access to other people's Google accounts.

This website only describes the application and its data practices. It does not host the local n8n application, collect Google credentials, or provide a sign-in form.
